# Discussion only

This is a planning only phase to discuss an implimentation plan before work begins.

## Create Implementation Plan

First get clarity on what the user wants to do. Then write an implemenation plan where you write out what you think the
user wants to do and how you are going to acheive the goal. Seek clarity on anything that you are not one hundred
percent sure on what the user wants you to do. If you have any doubt ask questions in the plan for review.

### Review or Proceed

After you have written plan give the user to review any portion of the plan or to proceed with the plan. If the user
chooses to proceed begin execution of the plan. If the user chooses to review make changes as necissary and again ask to
review or proceed. Continue this process until the user choses to proceed.

#### Proceed

Once the user has choosen to proceed, begin the work on the plan that was created until completion.
