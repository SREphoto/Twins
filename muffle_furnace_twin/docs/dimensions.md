# Dimensions — Muffle Furnace

For 3D model construction. Based on Nabertherm L 9/11 (primary target) and cross-referenced with L 3/11, Carbolite ELF.

## Primary Model Target: Nabertherm L 9/11

This is the most common lab muffle furnace configuration.

## Door (Flap Type)

| Parameter      | L 9/11 (mm)  | L 9/11 (in)  | Notes                              |
| -------------- | ------------ | ------------ | ---------------------------------- |
| Width          | ~360         | ~14.2        | Slightly wider than chamber        |
| Height         | ~240         | ~9.4         | Door overhang 240 mm when open     |
| Thickness      | ~30          | ~1.2         | With insulation                    |
| Hinge position | Bottom       | Bottom       | Flap door doubles as work platform |
| Handle         | Front center | Front center | Recessed grip                      |

| Material  | Kanthal or FeCrAl alloy | Embedded in ceramic fiber |

## Exhaust / Chimney (Optional)

| Parameter           | Dimension        | Notes             |
| ------------------- | ---------------- | ----------------- |
| Chimney diameter    | ~50 mm           | Natural draft     |
| Chimney height      | ~300 mm          | Above furnace top |
| Fan (optional)      | ~100 mm diameter | Assisted exhaust  |

## Notes

- All dimensions from Nabertherm official catalog (nabertherm_laboratory_catalog.pdf)
- Door overhang = depth the flap door extends forward when open (usable as work platform)
- Weight includes complete furnace with standard equipment
- Models with "LT" prefix = lift door; "L" prefix = flap door
- Power and electrical specs vary by model (see catalog table)
