# Bill of Materials — Glove Box (Inert Atmosphere)

Based on MBraun UNIlab Pro SP. For digital twin component identification.

## System Overview

1. **Chamber Assembly** — Main enclosure, windows, frame
2. **Glove Ports & Gloves** — Access ports and sealing gloves
3. **Antechamber** — Transfer chamber with doors
4. **Purification System** — Catalyst columns, blower, regeneration
5. **Gas Management** — Valves, regulators, sensors
6. **Control System** — PLC, touch panel, sensors
7. **Stand & Frame** — Support structure, leveling feet
