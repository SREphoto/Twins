# UV-Vis Spectrophotometer Digital Twin

Interactive 3D physical digital twin of a laboratory UV-Vis Spectrophotometer (UV-1900i class) with dynamic Beer-Lambert physics, wavelength scanning (190–1100 nm), 6-cell motorized carousel, and realistic procedural optics.

## Quick Start

### Standalone Package Viewer
```bash
./scripts/serve.sh
# http://127.0.0.1:8765/viewer/
```

### Run Unit Tests
```bash
./scripts/test.sh
```

### Master Lab Desk
From the Twins root:
```bash
./scripts/serve.sh
# http://127.0.0.1:8765/lab_viewer/
```
Select "Spectrophotometer" from the instrument catalog dropdown.
