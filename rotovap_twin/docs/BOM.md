# Bill of Materials — Rotary Evaporator

Based on Buchi R-300. For digital twin component identification.

## System Overview

1. **Drive Unit** — Motor, rotation mechanism, seal
2. **Glass Assembly** — Evaporation flask, condenser, receiving flask
3. **Heating Bath** — Bath, heater, temperature sensor
4. **Lift Mechanism** — Motorized lift, guide rails
5. **Stand** — Support frame, base, counterweight
6. **Control System** — Touch panel, controller PCB
7. **Vacuum System** — Vacuum controller, tubing (optional)
