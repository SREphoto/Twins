# Bill of Materials — Vortex Mixer

Based on Scientific Industries Vortex-Genie 2. For digital twin component identification.

## System Overview

1. **Motor Assembly** — Motor, eccentric weight, mounting
2. **Head Assembly** — Cup head or flat head
3. **Housing** — Enclosure, base, feet
4. **Controls** — Speed control, mode switch, power switch
5. **Electronics** — PCB, speed control circuit

## 1. Motor Assembly

| Item             | Qty | Description        | Material | Notes          |
| ---------------- | --- | ------------------ | -------- | -------------- |
| Motor            | 1   | AC induction or DC | Various  | 200–3200 rpm   |
| Eccentric weight | 1   | Offset mass        | Steel    | On motor shaft |
| Motor mount      | 1   | Bracket            | Steel    |                |
