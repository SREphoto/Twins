# Logs

All agents append here at end of session. Session procedure: [AGENT_SOP.md](../AGENT_SOP.md). Detail: [AGENTS_MANDATE.md](../AGENTS_MANDATE.md).

| File / dir                                       | Purpose                                  |
| ------------------------------------------------ | ---------------------------------------- |
| [master_change_log.md](master_change_log.md)     | Every create/change/delete/move          |
| [troubleshooting_log.md](troubleshooting_log.md) | Problems and fixes                       |
| [conversation_log.md](conversation_log.md)       | Session summaries                        |
| [report_cards/](report_cards/)                   | Self report cards (one file per session) |

**Convention:** newest entries at the **top** of each log file.

Templates: `../templates/`.
