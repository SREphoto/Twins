# Self score rubric (1–100)

Score **this session’s deliverables**, not the whole product history.

| Band   | Meaning                                                                                                             |
| ------ | ------------------------------------------------------------------------------------------------------------------- |
| 90–100 | Goal met; verified (tests/serve where relevant); accurate file lists; no known invented facts; clear pitfalls notes |
| 75–89  | Goal mostly met; minor gaps (e.g. one check skipped) honestly reported                                              |
| 60–74  | Partial progress; incomplete paths or unverified behavior                                                           |
| 40–59  | Substantial mistakes, rework needed, or weak evidence                                                               |
| 1–39   | Wrong direction, broken package, or serious unacknowledged hallucination                                            |

## Adjustments

| Situation                                              | Guidance                                               |
| ------------------------------------------------------ | ------------------------------------------------------ |
| Did not run tests that should have been run            | Cap at **80** unless tests are irrelevant to the task  |
| Guessed dimensions/control facts without labeling them | Cap at **70** and fill hallucination section           |
| OEM/legal claim without LIAR                           | Cap at **50**                                          |
| Skipped end-of-work logs                               | Cap at **40** (session incomplete)                     |
| Only docs/process, no code                             | Can still score high if docs are accurate and complete |

Integer only. One score per report card.
